# Argo Analytics – Frontend

## Purpose
Das Frontend bildet die WebApp von Argo Analytics: Dashboard, Watchlist, Scoring-Visualisierung, Unternehmensprofile und Interaktion mit der API. Ziel ist eine schnelle, modulare und skalierbare UI-Struktur.

## Tech Stack
- Next.js oder React
- TypeScript
- TailwindCSS oder eigenes Stylesheet
- Supabase Auth + API-Client
- Vercel / Cloudflare Pages Deployment

## Structure
/src  
  /components – UI-Bausteine  
  /pages – Views, Routing  
  /hooks – State & Data Hooks  
  /services – API-Calls  
  /styles – globale Styles  
/public – statische Assets  
/tests – Unit Tests  
/docs – technische Dokumentation  

## Roadmap
